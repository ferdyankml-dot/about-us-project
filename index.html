Visi & misi

Visi

Menjadi divisi Front End yang menghasilkan antarmuka rapi, konsisten, dan mudah digunakan untuk seluruh produk komunitas Code 124.

Misi

Membangun komponen yang bisa dipakai ulang, berbagi ilmu antar anggota, dan terus belajar praktik terbaik pengembangan antarmuka web.

Tugas divisi Front End

Hal-hal yang jadi tanggung jawab kami di setiap proyek Code 124.

  • 01

    Membangun struktur & tampilan halaman

    Menerjemahkan desain menjadi HTML dan CSS yang rapi, konsisten, dan mudah dipelihara.

  • 02

    Menjaga design system

    Mengelola token warna, tipografi, dan komponen dasar supaya seluruh halaman punya tampilan yang seragam.

  • 03

    Menghubungkan data dari API

    Mengambil data seperti daftar anggota dari endpoint PHP/JSON dan menampilkannya secara dinamis di halaman.

  • 04

    Memastikan tampilan responsif

    Menguji dan menyesuaikan halaman agar tetap nyaman digunakan di desktop, tablet, maupun ponsel.
